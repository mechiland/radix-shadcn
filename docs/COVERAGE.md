Known limits

- Visual comparison uses one pinned local Chromium on Linux and sRGB; system font stack resolves on that machine. It is not a cross-OS/browser certification.
- 100 gallery pairs cover all 45 sections in light/dark plus 10 open states (including a submenu and the alternate popper Select). The 12-combination multi-component matrix is representative, not every Cartesian permutation.
- Pixel difference values are diagnostics, not a claimed fidelity percentage. Open overlay placement/scrolling follows Base UI; see per-row notes and screenshots.
- Application examples are intentionally local demonstrations; no backend/account/payment/generator service is provided.
